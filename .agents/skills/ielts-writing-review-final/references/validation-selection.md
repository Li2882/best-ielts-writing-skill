## 当前 v1.4：从路线筛选到锚点校准

原初评提示词、关键词和分档要求保持不变；证据核验不增加扣分、免扣或封顶公式。大小作文八项分别校准：6/7/8/9 整数档逐格读取同任务、同分项参考，半分位置比较相邻整数档，记录强于、相当、弱于和不确定的证据。

2026年10月1日完成 28 篇开发回归：单篇总分覆盖 6—9，每隔半分，每种作文每档 2 篇。初评总分 MAE 为 0.518，校准后为 0.482；误差≤0.5 的比例从 78.6% 变为 82.1%。配置、缺项和数值记录见项目根目录 `docs/research.md` 与 `research-data/current-evaluation.json`。

## 当前执行路由

- **Task 1 TA / Task 2 TR**：使用 quyen 初评路线，再做同任务、同分项锚点校准。
- **CC**：使用 Gishguo 初评路线，再做同任务 CC 锚点校准。
- **LR**：使用 V4 成功词汇 `provisional_score`，问题卡只用于诊断和反馈；之后做成功词汇范围内的同任务锚点校准。
- **GRA**：使用 independent V4 初评，再做同任务 GRA 锚点校准。
- **所有分项**：初评先锁定；校准只根据可核对的双向证据调整 `anchor_adjustment`；最终分为 `provisional_score + anchor_adjustment`，限制在 0—9。

## 资料和输出

只把 `status=verified`、`split=reference`、任务类型匹配且有明确人工标签的样本作为锚点参照。实际读取样本的题目、原稿、评语和 Task 1 图表；留出样本不作评分参照。报告保留初评、锚点调整、最终分、证据、参考编号和缺项。

README 的 28 篇数据是当前版本的开发回归记录。改变模型、推理档、参考库或评分路由后，应建立新的版本记录，不沿用旧配置的结果。
