# 证据核验与整数锚点双向校准 v1.4

更新日期：2026-09-30（UTC）。适用于 final-composite-1.4；用户已授权32格整数补库及28篇测试，结果尚待实际完成。

机器可读约束见 [calibration-policy.json](calibration-policy.json)，原文件锁见 [baseline-lock.json](baseline-lock.json)。两者与本说明须保持一致。

## 范围与不变项

- 大小作文各四项都进入锚点复核，任务和评分项分别处理。参考库建设为6、7、8、9整数档，每格至少10篇；校准输出仍允许半分，不扩建更低分档。
- 6 是本次研究范围下界，不是最低给分。原提示词若给出更低分，原样保存并标记 out_of_focus，不把分数抬至 6；低于范围的校准暂不展开。
- 原初评提示词、关键词、描述符和初评路线保持不变。文件清单及 SHA-256 见 baseline-lock.json；不得只保证文件没改，却在外围指令中把 fully 改成 mostly、把精确性要求放宽或新增苛刻要求。
- 原始作文、已核实图表和初评的全部成功证据保留；不先润色作文再评分。
- 核验只确认事实，不输出档位、扣分数、自动封顶、宽容阈值或目标分。最终分不是直接固定为初评，而是初评加上有依据的锚点调整。
- LR 继续只从成功词汇获得 provisional_score。问题卡不重新计算该分、不进入成功词汇锚点比较、不否决上调、不在最终分后再扣分。
- 本轮已获授权运行指定28篇测试，须先满足资料配额并冻结输入；未授权限幅对照，测试结果不能倒推修改原规则。

## 1. 证据核验：判断问题成立与否，不另创评分标准

在形成初评分数前核实证据，仍由原初评提示词评价原文。事实卡不包含建议分数，也不预先决定某档是否可得。对准备指出的问题，记录：

| 字段 | 应记录的内容 |
| --- | --- |
| quote / context | 原文逐字引用、句段位置及必要上下文；不得引用改写版本 |
| claim | 具体声称存在什么问题，不能只写“不够高级/不够地道” |
| verification | 核对原图/题目、完整句法关系、所指对象或可靠语言资料的结果；缺失资料明确注明 |
| status | confirmed_error / optional_improvement / unresolved；组织、范围或覆盖不足另记 performance_observation，不强称语法错误 |
| occurrence / scope | 实际出现位置与次数、局部或分布情况；重复家族去重，但保留真实频率 |
| accuracy / communication | 分别说明准确性缺口与实际歧义、回读负担或理解中断；不互相替代 |
| provenance | 来源、版本、原文定位和核验依据；不确定性不能包装成确定错误 |

执行要求：

- 时间、数字和比较先对原图，再明确时间短语修饰的对象或阶段。“40 年/30 年”不能脱离句子直接判错，也不能因错误成立就自动规定 TA 档位。
- 指代要列出在上下文中可成立的先行词。能更直接不等于已有歧义；同样不能为了保分，把真实的多重指向说成没有问题。
- 判断语法前分析完整句子、从句、省略与修饰范围；一个可成立的句法解释不能仅因少见而被否定。需要异常牵强解释才能成立时，如实说明不确定性。
- 选词、搭配、拼写与词形证据分清；不以“有更优替换词”为判错证明，必要时查词典或可靠用例。不确定时标 unresolved，不擅自保证正确。
- 可理解的语法错误仍可能是准确性问题，不再次伪称沟通受损。没有硬错误也不证明结构、词汇范围、任务覆盖或组织已充分。
- 这些核验不规定少量错误免扣，也不规定一处错误必须扣分；分档仍由原提示词及后续同维度锚点比较完成。
- 核验应在初评锁定前完成。若锁定后发现证据错误，保留旧记录、注明失效原因，按同一原提示词建立新的初评版本；不得手动补半分、无痕覆盖或为追求分数反复重跑。没有发现可核对的事实错误，不重做初评。
- 核验不能消除原文的真实错误，也不能给锚点作“修正后评分”。候选与锚点采用同样的原稿核验原则。

## 2. 独立初评与阶段隔离

实际读取评分核心所列的原提示词和相应描述符，不用本文件的摘要替代原文。初评不看锚点、其标签、教师评语、历史预测或用户期望分数。

锁定 task、criterion、original_essay_sha256、prompt_paths_and_hashes、provisional_score、初评证据和理由。LR 只运行 V4 Mandatory procedure 第 1 步及其成功词汇匹配，仍不运行第 2–5 步。

锚点比较不得回写 provisional_score。给初评更正编号不等于修改原提示词；更正原因必须是可核实的证据错误，而非校准阶段不喜欢原分数。

## 3. 整数分项锚点与测试配额

1. 本轮建设6、7、8、9四个整数档；Task 1的TA/CC/LR/GRA与Task 2的TR/CC/LR/GRA分别至少10篇去重的合格原稿，共32个配额格。一篇原稿可按其真实不同小分进入不同格，但在同一格只能算一次。
2. 只用同任务、真实人工分项、verified + reference、label_scope=individual的材料；不把总分反推成小分。教师原创稿仍须独立人工评分。原稿、题目和Task 1题图须可核验，重复转载和修订稿不重复计票。
3. 不再要求先补齐6.5、7.5、8.5分项标签。既有真实教师半分照录并保留出处，但不改成整数，不计入整数配额。项目输出的分项半分是相邻整数描述符之间的内部边界估计，不冒充官方独立半分档。
4. 半分比较分别使用相邻低整数档和高整数档。两组不能合票、平均标签或改标。每个用于决定定位的整数档实际读取至少10篇独立原稿，并记录来源分布；原稿及任务机会不合格的样本不投票。
5. 配对仍只记录weaker/comparable/stronger/uncertain及双方原文证据。按整数档列出票数和分母；不确定票不得偷偷删除，并列或证据冲突不强定多数。多数只是比较汇总，仍须描述符与整体证据支持，不能自动套用“过半即加0.5”。
6. 初评附近逐半分比较，允许上下移动且暂不设相对限幅。真实的半分位置须同时说明低档、高档和候选的差异；材料不足明确记录，不把缺口变成得分上限。
7. 新线索先登记candidate，核验原稿、标签、评分者、题图及重复后再入库；最终联合评分优先，不挑旧评分或平均多位评者制造标签。保留未接纳原因及实际检索记录。
8. 用户授权测试：按已发布单篇总分6、6.5、7、7.5、8、8.5、9，每任务每档2篇，共28篇。测试样本与锚点按原稿、重复组和可识别题目组隔离；原始总分不以项目均值重算。
9. 方法、输入与锚点版本冻结后评分。全部初评和最终预测锁定后才计算人工标签误差；不能从少量试跑挑选有利结果。已使用样本只称开发回归，公开新样本也披露潜在预训练污染。
10. 报告初评和校准后总体、分任务、分档及有真实标签的分项MAE/RMSE/Bias/完全一致率/误差≤0.5比例，并给各自N。缺少人工小分不反推，不生成假的分项MAE。未完成28篇或锚点配额必须明确披露，不能宣称本轮已完整完成。
11. 本次不研究相对限幅，不购买资料或新订阅。授权评分实验不等于已证明准确率提高。

## 4. 比较内容与输入隔离

| 项目 | 比较范围 |
| --- | --- |
| Task 1 TA | 原图对应的主要特征、总览、覆盖、比较与数据事实准确性；优先可比图表/流程/地图机会 |
| Task 2 TR | 题目覆盖、立场、论点和展开支持；不能把 Task 1 数据细节规则搬来 |
| CC | 组织、推进、段落、衔接、指代在全文中的实际效果 |
| LR | 仅成功词汇的范围、灵活性、精度、自然搭配和任务相对表达能力；不输入问题卡，不比较错误、重复、拼写、别扭表达和可能的改写 |
| GRA | 实际成功结构、无错误句/分句分布、语法标点控制与真实沟通影响；不只数错误或长句 |

先逐篇比较，再查看锚点标签定位。比较输入隐藏初评分、目标档、标签、作者/来源名、其他小分和教师评语；使用中性别名。检索者可知道标签，但比较记录不得借标签代替论证。一个对话内只能做到逻辑隔离，不能声称达到真正盲评。

每一候选—锚点配对只记录一次主判断，输出 weaker / comparable / stronger / uncertain，以及双方可核对的同维度证据和判断理由。重复出现于不同边界时复用该记录，不算新票；关键边界可交换顺序复核，保留两次结果和冲突，不挑有利答案。

比较整体表现，而非只比较同一种瑕疵。不能因为锚点有一个相同错误就认定两篇同分，也不能因候选没有该错误就认定更高。原有正向要求仍须满足，LR 限定除外不额外加入错误维度。

## 5. 双向、逐半分定位，暂不限制调整幅度

- 从锁定初评附近开始，检查当前与相邻位置；由证据决定向上或向下，不默认只上调。
- 精确标签位置使用多篇不同原稿，逐项说明该位置的总体比较结论及异议。不同来源、题目与作者尽可能分散；单篇不决定移动。
- 比较混合时先补样本、核对原稿与配对理由；不能“搜到支持目标分为止”或丢弃反对证据。保留检索到且合格的反向证据。
- 半分边界必须在 lower 与 upper 两个相邻整数组分别建立证据。不能把“三低三高”混成一个 4/6 投票；不能算均值、平均标签或把某篇整数作文改标半分。
- 上下组只证明一个区间，不自动证明中点。须说明同维度整体表现为什么支持该半分位置，而不是两端位置；依据不足记 unresolved，不能直接平均得到半分。
- 每移动 0.5 都记录 position、integer / integer_bracket、anchor_ids、比较依据与 supported / unsupported / unresolved。可继续跨越多个半分，但不跳过失败或未解决的中间边界。
- 对更高标签更强、对更低标签更弱等明显矛盾，检查任务机会、来源和原稿，复核关键配对。仍冲突则该项不调整并说明原因，不自动取低分。
- 不设置 +/-0.5、+/-1、+/-1.5 或 +/-2 的相对幅度上限；允许有连续充分证据的较大变动。不可把旧 LR V8 限幅、TR V3 数量封顶、GRA 向上门槛换个名字重新引入。
- 连续证据已支持的最后位置可作为校准结果；没有任何可靠移动证据、原稿不完整或整体定位冲突时，保留初评并标明未校准原因。
- 若证据指向低于本次覆盖范围，报告 out_of_focus，不将其伪装成已确认的 6；不为此临时扩展低分库。9 分无更高邻档，不要求虚构 9.5 锚点。
- final_score = provisional_score + anchor_adjustment；最终范围 0–9、半分网格。不再有后置扣分、错误否决门或根据改写建议改分。
- 这是当前工作方法，不是经验证的最佳比较票数/阈值；不得补写一个未经用户同意的机械多数票升级公式。

## 6. 报告与可审计记录

沿用五部分报告。在分数表中增加“独立初评 / 锚点调整 / 最终分 / 校准状态”；每项记录：

- 使用的原提示词及哈希、锁定初评理由；
- 核验事实、成功证据、诊断问题与待核实项；
- anchor_ids、任务和真实分项标签、来源/原稿定位、是否用了整数边界及检索记录；
- 逐配对和逐半分比较结果、反向证据、移动或不动的理由；
- 校准前后分数；问题卡尤其 LR 不含算术扣分。

“确实影响档位”须引用原初评或实际锚点比较中的证据；没有依据的“还能更好”只作可选优化，不倒推分数。真实错误可以记录而不声称它单独造成半分差距；真实表现不足也不必须表现为语法错误。建议阶段不再次评分。

指定28篇测试完成后计算真实指标，保留初评与校准后结果。资料或执行不足时报告实际完成数，不把结构检查当准确率结果；不因看到误差而在同一测试集上调规则后声称新盲测。
