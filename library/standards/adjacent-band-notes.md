# 相邻档对照笔记：开发用途

2026-09-21。只记录实际读到的原稿与人工评语；不是替代官方描述表的新门槛。不同题目的比较不能证明仅改变某一点就必然升半分，整篇总分也不能反推出四项。

## Task 1：语言好不等于任务完成度同样高

`insights-v11-p39-task1`，机票价格图，教师原稿，Tony 总分 7.5，明确分项 TA7、CC7、LR8、GRA9。原稿和图见报告第 39、40 页，四项评语第 41、43、45、46 页。作者语言丰富且语法控制很强，但逐日叙述价格使信息呈现机械，overview 还能概括更多关键关系。不能因为 GRA9 就把 TA、CC 一起抬到 9；也不能因总分 7.5 把语法降到 7。

`insights-v14-p22-task1`，男女比例表，教师原稿，Tony 总分 8.5。原图第 22 页，原稿第 23 页，TA 评语第 24 页确认概述清楚、信息准确。比较时先看信息选择、分组和跨地区关系是否清楚，再看是否存在真正影响理解的错误。两篇不同题，不能简单推导“写表格就比折线高一分”。

`farzad-task1` 同一原稿两位评阅分别给 7 与 7.5，发布方最终结果为 7.5。该案例用于提醒人工存在边界分歧；不能挑与模型最接近的那个评分，也不能把一次 0.5 差距直接解释成模型或教师必然错。

## Task 2：高分仍可有可选修改

`insights-v11-p26-task2`，博物馆教育与娱乐，教师原稿，总分和四项均为 9。已读第 27、28 页完整原稿，以及第 29、32、35、37 页四项说明。评语认可完整回应、明确立场、连贯展开、灵活准确的词汇及句型；后文仍提供局部替换建议。**可提出修改，不代表必须扣分。** 同时，这只是一个教师练习稿的人工判断，不能据此认定所有看似流畅的文章都应 9。

`insights-v21-p40-task2`，整容原因与评价，总分 8.5。TR 页指出一处因果表述值得调整，但仍判 TR9；应判断论证整体是否充分，区分局部争议、逻辑断裂与答非所问，不能按建议条数扣分。
