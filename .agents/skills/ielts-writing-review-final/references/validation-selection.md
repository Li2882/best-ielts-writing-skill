# 组合选择与验证边界

## 当前 v1.4：整数锚点及已完成开发测试

原初评提示词、关键词和分档要求保持不变；证据核验不增加扣分、免扣或封顶公式。大小作文八项分别校准：6/7/8/9整数档每格至少10篇合格独立原稿，半分用相邻整数组分别比较。记录强于、相当、弱于、不确定的票数及证据，不把多数直接转换为加减分；双向逐半分，暂不限相对调整幅度。

2026-10-01已完成28篇开发回归：单篇总分6—9、每隔半分、每种作文每档2篇。整体总分MAE为0.482，误差≤0.5比例为82.1%；配额缺口、测试配置和数值记录见项目根目录 `docs/research.md` 与 `research-data/current-evaluation.json`。这不是全新盲测，也不是当前版对其他项目的同批对照。历史授权不适用于新用户，不自动重跑测试或启动限幅实验。

完整规则见[证据核验与校准](evidence-anchor-calibration.md)。以下保留历史选择证据，不能把历史分项指标冒充当前整体成绩。

## 明确未采用

- 四项固定补偿：组合留出四项 MAE 从 0.734 恶化到 0.828。
- 对 Task 1 TA 使用 V3：共享新集从 0.25 恶化到 0.50。
- LR 在 `provisional_score + anchor_adjustment` 之后的独立词汇扣分：旧八篇开发消融中使 MAE 从 0.375 恶化到 0.500，并扩大向下偏差，因此不采用。
- 把成功词汇与问题证据重新合并成未经测试的整体 `base_score`，或让错误控制进入原本只比较成功词汇的锚点阶段：本次消融没有验证这些改法。
- 把上述 0.375 宣称为纯 V4、V15/V16 或新盲测成绩：消融固定的是 V12 已保存的初始判断与锚点调整，只验证是否保留后置独立扣分。
- GRA 六锚点向上校准：共享新集从 0.875 恶化到 0.938。
- 用一种共享上调门同时处理 TA 与 TR：两项在新集上的误差方向不同。

## 能声明与不能声明的结论

可以声明：v1.2有上述历史选型证据，LR的开发消融支持取消第二次独立扣分；v1.4保留原初评并按用户要求使用整数锚点双向校准。不能将旧版成绩移作v1.3成绩，也不能声称v1.4是新的验证冠军。

不能声明：该组合本身已在完整新留出集上正式盲测；达到考官级准确率；MAE 达到 0.1；公开教师标签等同官方真考成绩；同一批已经揭示标签的文章仍是新测试。

该组合改变了既有四项路由，所以将来若要发布准确率，必须冻结本版本后，在从未揭示四项标签的新样本上整体测试，分别报告 Task 1、Task 2、四项 MAE、偏差、完全一致率和误差不超过 0.5 的比例。
